# Seb documentation

Use these guides in order.

1. [Set up Seb](SETUP.md) for installation and basic verification.
2. Read the [command-line guide](CLI.md) for chat, pipes, JSON, and diagnostics.
3. Read the [interactive guide](INTERACTIVE.md) for commands, context, skills, and exports.
4. Read the [terminal interface guide](TERMINAL_UI.md) for editing, history, themes, and display behavior.
5. Read the [AI SDK guide](AI_SDK.md) for grounded news, typed results, and local traces.
6. Read the [storage guide](STORAGE.md) for caches, snapshots, and migration.
7. Read the [identity guide](IDENTITIES.md) for canonical players and teams.
8. Read the [provenance guide](PROVENANCE.md) for source lineage and freshness.
9. Read the [evaluation guide](EVALUATION.md) for replays and metrics.
10. Read the [data source guide](DATA_SOURCES.md) for source-specific details.
11. Read the [skill guide](SKILLS.md) for each analysis workflow.
12. Read the [architecture guide](ARCHITECTURE.md) before a source or agent change.
13. Read the [versioning guide](VERSIONING.md) before a release.
14. [Choose a connector](CONNECTORS.md) for Slack, Discord, or Telegram.
15. Follow the platform guide in the [connectors folder](connectors/README.md).
16. Read [production operations](OPERATIONS.md) before a public deployment.
17. Read the [V1 design](V1.md) for injuries, projections, and simulations.

The current connector code supports Slack, Discord, and Telegram.

Chat SDK supports more official platform adapters. The [other platforms guide](connectors/OTHER_PLATFORMS.md) lists them.

The [custom adapter guide](connectors/CUSTOM_ADAPTER.md) explains how to connect another platform.
