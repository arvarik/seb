# Version 1 scope and roadmap

Version 1 provides a grounded NFL research and fantasy decision assistant combining deterministic TypeScript calculations, public-source provenance, multi-provider AI SDK orchestration, and multi-channel delivery. See the [versioning guide](VERSIONING.md) for public CLI, JSON, and webhook compatibility guarantees.

## Available in Version 1

| Capability | Shipped implementation (`v1.0.0` – `v1.1.2`) |
| --- | --- |
| **NFL data & 47 newsrooms** | Sleeper leagues/matchups/waivers, nflverse schedules/player/team/play-by-play CSVs (with 15m live-score revalidation), NWS weather, and **47 built-in 3-tier news sources** indexed in **SQLite FTS5 (`news_articles_fts`)** with **36-hour `corroboratedBy` event clustering** (`v1.1.0–v1.1.1`). |
| **Model providers & harness** | Google Gemini (with Search & URL Context), Anthropic (with ephemeral `cacheControl`), OpenAI, and OpenAI-compatible endpoints on a 16-step `ToolLoopAgent` with `toModelOutput` compaction and `inspectSystemDocs`. |
| **Terminal UX & sessions** | Interactive TUI with experience routing, slash palette, stream cancellation, ANSI sanitization, **resumable sessions (`SessionStore` via `seb resume <id>` / `seb sessions`)**, copy/export, and `CachedResource` L1 + SQLite L2 caching. |
| **Offensive, K & D/ST forecasts** | League-scored `QB`, `RB`, `WR`, `TE`, `K`, individual special-teams (`st_td`, `st_ff`, `st_fum_rec`, `st_tkl_solo`, return yards), and **team D/ST (`DEF`) projections** (`v1.0.2`) with empirical 80% residual intervals. |
| **Lineup, covariance & analysis** | **`optimizeRosterLineup` combinatorial starter solver** (up to 12 non-bench slots & 60 candidates), **`sameGameCorrelation` intra-game covariance** (`v1.1.1`), automatic flex inference in `compareStartSit`, `projectLeagueMatchup`, `analyzeTradeImpact`, `rankWaiverTargets`, and `simulatePlayoffOdds` (with optional `matchupCorrelation`). |
| **Decision Gate & auto-recovery** | Deterministic action gate with **single-retry stale/missing-evidence auto-recovery** (`v1.1.2`), 5-minute prior-turn evidence reuse, and verified inactive/bye/illegal-slot refusals. |
| **Local weekly learning** | Explicit post-week `seb learn update` workflow with chronological train/validation splits, MAE/RMSE promotion gates, SHA-256 revisions, and bounded `overrides.json`. |
| **Chat connectors** | **Slack, Discord, Telegram, and GroupMe** (`v1.1.0`) with shared two-minute deadlines, Redis locking/queueing, and unified `~/.config/seb/` + environment configuration. |
| **Observability & distribution** | Metadata-only SQLite usage analytics (`SebUsageTelemetry`), dev-only `@ai-sdk/devtools`, **optional Judgment OpenTelemetry tracing**, and automated CD publishing to **npm (`@arvarik/seb` with SLSA provenance)** and **GHCR (`ghcr.io/arvarik/seb`)**. |

Seb is strictly read-only against external fantasy platforms and never submits lineups, waiver claims, trades, or commissioner edits. Local writes stay confined to `~/.config/seb/`, `.cache/seb.sqlite`, `.cache/learning/`, explicit report exports, and dev-only traces.

## Current limits

- **Authoritative feed boundaries**: Seb has no licensed commercial wire, official NFL injury/practice participation feed, or proprietary projection feed; Sleeper player status does not replace official club injury reports, NWS weather covers U.S. venues only, and model prose still requires user review.
- **Scoring & roster boundaries**: Projections cover `QB`, `RB`, `WR`, `TE`, `K`, and team `DEF` under the rules in the [analysis guide](ANALYSIS.md); individual defensive player (`IDP`) projections and unrecognized custom league scoring keys remain explicitly flagged rather than substituted with `0`. Trade evaluations exclude draft picks and dynasty market values, and waiver rankings/FAAB bids use stated heuristics.
- **Simulation & platform scope**: Playoff Monte Carlo simulations draw from blended roster-level score distributions (with optional head-to-head `matchupCorrelation`) over contiguous known schedules; they do not simulate week-by-week player injuries, future waiver pickups, division winners, or custom commissioner seeding. Automated CI runs on Linux and macOS (Node.js 22); Windows is not covered in CI.

## Future work

The items below outline candidate directions rather than committed timelines:

- Add persistent cross-session news review state and explicit user confirmation workflows for breaking status changes.
- Integrate an authorized injury-report and depth-chart feed with verified publication timestamps.
- Benchmark play-by-play expected fantasy opportunity (`ff_opportunity`) and explicit snap/route role-change features against walk-forward baselines before promotion.
- Add forecast-diff explanations attributing point shifts between saved runs to exact stat, schedule, weather, or parameter changes.
- Expand custom scoring, IDP, and division/custom playoff seeding coverage backed by real league test fixtures, plus dedicated Windows terminal/CI verification.

Every addition must uphold source terms of service, bounded storage, `AbortSignal` cancellation, deterministic regression coverage, and documented extension steps in the [architecture guide](ARCHITECTURE.md#extension-points).
