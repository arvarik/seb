# Version 1.0 scope and roadmap

Version 1.0 provides a local NFL research assistant with documented commands, evidence records, and deterministic fantasy calculations.
The [version guide](VERSIONING.md) defines the supported public interfaces.

## Available in 1.0.0

| Capability | Implementation and limits |
| --- | --- |
| NFL research | Sleeper league data, nflverse schedules and weekly statistics, and 44 direct news sources |
| Model providers | Google Gemini, Anthropic, OpenAI, and OpenAI-compatible endpoints with streaming and tool calls |
| Terminal interface | Subject context, commands, cancellation, source inspection, history, selection, copying, and exports |
| Player forecasts | Offensive player estimates with league scoring, historical inputs, bounded adjustments, and uncertainty ranges |
| Fantasy analysis | Starter comparisons, heuristic waiver rankings, exact offensive trade lineups, and roster playoff simulations |
| Local learning | Explicit updates after completed games, chronological validation, immutable revisions, and bounded overrides |
| Evidence | Validated source URLs, timestamps, cache status, snapshots, and field lineage |
| Chat connectors | Slack, Discord, and Telegram with shared deadlines and optional Redis state |
| Evaluation | Historical replay, forecast comparison, regression tests, coverage checks, and live diagnostic commands |

Seb reads external football data. It never submits a lineup, waiver claim, trade, or league setting.
Local commands and tools can write preferences, caches, snapshots, learning revisions, history, exports, and usage metadata.

## Limits at release

Seb has no official injury-report feed, licensed publisher feed, or official projection feed.
Sleeper player status does not replace an official injury report.
Public data can lag games or become unavailable. Model explanations can contain errors.

Player forecasts support QB, RB, WR, TE, and K statistics for the scoring rules in the [analysis guide](ANALYSIS.md).
Missing statistics and unsupported active scoring rules restrict recommendation eligibility.
Trade estimates exclude draft picks and market prices. Waiver scores and bids use stated heuristics.

Playoff simulations use independent roster score distributions and known remaining opponents.
They exclude divisions, commissioner seeding, player correlations, and future roster changes.
Historical benchmarks do not establish live lineup performance.

Learning requires an explicit request. Seb does not install a background schedule.
NWS forecasts cover United States venues only.

CI runs on Linux and macOS with Node.js 22. Windows has no CI coverage.
Releases are distributed via the automated CD workflow to npm (`@arvarik/seb`), GitHub Container Registry, and GitHub Releases.

## Future work

These items describe possible extensions. They do not describe implemented features or promised delivery dates.

- Add persistent news review, duplicate-event grouping, and explicit confirmation states.
- Add an authorized injury and depth-chart source with publication timestamps.
- Evaluate opportunity features, role changes, and correlated player outcomes against chronological baselines.
- Explain changes between saved forecasts with exact input and parameter differences.
- Extend supported scoring and playoff formats with fixtures from those leagues.
- Add platform-specific installation and terminal checks before claiming Windows support.

Every extension needs source terms, bounded storage, cancellation, regression tests, and accurate documentation.
Use the [architecture guide](ARCHITECTURE.md#extension-points) when adding a source or tool.
